Software Projects and Interactive Demos

Experiments built to learn by doing: cellular automata, GPU graphics, machine learning, algorithms, and procedural systems.

  1. Homelab AI Benchmarks Reproducible local model evaluations on NVIDIA DGX Spark hardware, including agentic delivery, inference performance, optimization and ARC. Preliminary failures remain visible alongside successful measurements. View the methodology and harnesses.
  2. Wolfram Cellular Automata Explorer Interactive online explorer for all 256 elementary rules. Start from one cell or a random state and change the active rule in real time.
  3. Conway's Game of Life Simulator An interactive cellular automaton implemented with Rust and WebAssembly. View source on GitHub.
  4. WebGPU Mandelbrot Set Explorer A real-time Mandelbrot fractal renderer for the browser using Rust, WebAssembly, and WebGPU. View source on GitHub.
  5. Conway's Game of Life Using Convolutions Fast cellular automata epochs using convolution kernels, including a custom algorithm for finding loops in the simulation.
  6. DeepCoinCounter A machine-learning proof of concept for counting cash automatically from a phone camera using augmented image data and TensorFlow Lite models.
  7. Geometric Morphometrics for Malnutrition Classification Master's thesis project applying classification models to landmark configurations for acute malnutrition diagnosis.
  8. Zeckendorf Codes A file compressor based on a custom algorithm using Zeckendorf representations.
  9. Procedural Algorithms in Unity Experiments with procedural cave generation and related algorithms in Unity.
  10. Binance Arbitrager A Julia experiment for detecting triangular arbitrage using nanosecond-scale graph algorithms and a custom Binance API client.
  11. Python Tara Game An early Python game project exploring search trees and pruning.
